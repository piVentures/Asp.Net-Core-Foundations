# 📁 FileDemo.Api

ASP.NET Core Web API for file management using:
- Azure Blob Storage (Azurite locally)
- Local file storage

---

## 🚀 Features

- Upload, download, and delete files via Azure Blob Storage
- Upload single and multiple files locally
- Download files by name from local storage

---

## ⚙️ Prerequisites

- .NET 6+
- Docker

---

## 🐳 Run Azurite

Run:

```bash
docker compose up -d
```

## Run the API
  dotnet run
